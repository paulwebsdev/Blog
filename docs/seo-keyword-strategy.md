# PaulNova SEO and keyword strategy

Updated: 19 November 2026

## Positioning

PaulNova publishes practical, evidence-led explainers across technology, artificial intelligence, digital business, education and careers. The goal is to answer real questions better than a generic keyword page. Do not create thin pages or repeat keywords unnaturally.

## Article optimisation checklist

1. Choose one primary search intent per article.
2. Write a clear title that naturally includes the primary phrase.
3. Use the main phrase or a close variant in the opening paragraph and one useful subheading where it fits.
4. Include related questions and synonyms only when they help answer the reader.
5. Write a unique meta description that accurately summarises the article.
6. Add descriptive image alt text; use the existing public Blogger image URL workflow.
7. Add 3–8 accurate topic tags and link to related PaulNova articles.
8. Include author information, publication date and meaningful updates.
9. Link to trustworthy primary sources for claims, statistics and changing information.
10. Avoid keyword stuffing, fake search volume claims, mass-produced pages and promises of guaranteed rankings.

## How to validate and improve

- After launch, verify the site in Google Search Console and submit the XML sitemap.
- Use Search Console's Performance report to find actual queries, impressions, clicks, click-through rate and average position. Review queries by page and country.
- Compare Nigeria and worldwide performance separately. Add country-specific wording only when the article genuinely serves that audience.
- Use Google Trends for direction and seasonality; use Keyword Planner or a reputable keyword dataset for estimated volumes and competition.
- Refresh article briefs monthly based on Search Console data and reader behaviour. Prioritise pages with impressions but weak click-through rate, and useful queries for which PaulNova is not yet answering the question.

## Measurement notes

The first-party PaulNova search index searches article titles, excerpts and body content. Topic pages and author pages are included in the sitemap. Search engine visibility is separate from the website's own search box: the site must be publicly deployed, crawlable, indexed and earn relevance and authority before it can appear for competitive queries. No implementation can guarantee a first-page ranking.
