# PaulNova

**Technology. Intelligence. Opportunities.**

PaulNova is a global digital publication covering technology, artificial intelligence, digital business, money, education and careers.

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Ready for Supabase integration
- Article images use public image URLs (including Blogger-hosted URLs); no image upload storage is required.

## Development
`npm install`
`npm run dev`

## Deployment
Connect this repository to Vercel. Configure the production domain when it is registered and point DNS to Vercel.

## Current status
Initial responsive publication frontend. Database-backed publishing and the private admin dashboard are planned as the next development phase.
