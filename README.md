# PaulNova

**Technology. Intelligence. Opportunities.**

PaulNova is a global digital publication covering technology, artificial intelligence, business and money, education and careers.

## Stack
- Next.js 15 App Router
- TypeScript and Tailwind CSS
- Ready for Supabase-backed publishing and private editorial tools
- Public image URLs (including Blogger-hosted image URLs); no image upload storage is required

## Development
```bash
npm install
npm run dev
```

## Current public-site foundation
- Responsive, mobile-first homepage and navigation
- Four dedicated editorial category pages
- Article pages with canonical URLs, metadata and social sharing metadata
- Search across the current article library
- XML sitemap and robots.txt generated by Next.js
- Article model supports external image URLs and descriptive alt text

## Deployment
Connect this repository to Vercel. Set `NEXT_PUBLIC_SITE_URL` to the production domain when DNS is configured. Add Supabase environment variables when the database integration phase begins.
